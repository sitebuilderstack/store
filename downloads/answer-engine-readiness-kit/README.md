# Answer engine readiness kit

Two files for making a page quotable by AI assistants.

| File | What it is |
| --- | --- |
| `ai-crawlers-robots.txt` | Commented robots.txt blocks for the ten AI crawler user agents, with each vendor's own description quoted and sourced. Three positions to choose between. |
| `answer-engine-readiness-checklist.md` | The per-page checklist: fetchability, whether a passage can be lifted, attribution, specificity, structure. |

From [SiteBuilderStack](https://sitebuilderstack.com). Free to use and adapt.

---

**Nothing here promises a citation.** No answer engine publishes its extraction
or citation rules, there is no equivalent of a ranking-factors list, and no tool
can verify you will be quoted. What these files cover is the part that is
observable: whether your page can be fetched, whether a passage survives being
lifted out of it, and whether the claim can be attributed to anyone.

Every crawler behaviour quoted in `ai-crawlers-robots.txt` carries its source
and the date it was read — 25 September 2026. This part of the web changes
faster than most, so check the source before relying on it rather than trusting
a file you downloaded.

The single most useful idea in either file: **write so that any one paragraph
can be removed from the page and still be true, still make sense, and still say
who is claiming it.**
