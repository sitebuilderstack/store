# AI crawler directives for robots.txt
#
# Every behaviour noted here is quoted from the vendor's own documentation,
# read on 25 September 2026. Check the source before relying on it — this part
# of the web changes faster than most.
#
#   OpenAI      https://developers.openai.com/api/docs/bots
#   Anthropic   https://support.claude.com/en/articles/8896518-does-anthropic-crawl-data-from-the-web-and-how-can-site-owners-block-the-crawler
#   Perplexity  https://docs.perplexity.ai/guides/bots
#   Google      https://developers.google.com/search/docs/crawling-indexing/google-common-crawlers
#
# From SiteBuilderStack — https://sitebuilderstack.com
#
# ---------------------------------------------------------------------------
# BEFORE YOU PASTE ANY OF THIS
#
# No directive at all is the same as ALLOWED. A crawler with no matching
# User-agent group falls through to the "User-agent: *" group, which on most
# sites permits everything. If your robots.txt mentions none of these agents,
# they are already allowed. Adding an explicit rule changes nothing technically
# — it changes what the next person to read the file can tell about your
# intent, which is a decent reason to add it anyway.
#
# Pick ONE of the three blocks below. Do not paste all three.
# ---------------------------------------------------------------------------


# ===========================================================================
# BLOCK A — allow everything. You want to be cited and you accept training use.
# ===========================================================================

# Nothing to write. Your existing "User-agent: *" group already allows them.
# If you want the decision to be visible rather than implied:

# User-agent: OAI-SearchBot
# User-agent: GPTBot
# User-agent: Claude-SearchBot
# User-agent: ClaudeBot
# User-agent: Claude-User
# User-agent: PerplexityBot
# Allow: /


# ===========================================================================
# BLOCK B — allow search, block training. The common middle position.
#
# The vendors split these into separate tokens deliberately so this is
# expressible. You stay quotable; your content is not used to train models.
# ===========================================================================

# Training crawlers — blocked
User-agent: GPTBot
Disallow: /

User-agent: ClaudeBot
Disallow: /

# Search / citation crawlers — allowed
User-agent: OAI-SearchBot
Allow: /

User-agent: Claude-SearchBot
Allow: /

User-agent: PerplexityBot
Allow: /

# Google's Gemini training and grounding. NOT a crawler — a control token.
# Google states it "does not impact a site's inclusion in Google Search nor is
# it used as a ranking signal in Google Search", and that it "doesn't have a
# separate HTTP request user agent string". Blocking it does not stop Googlebot
# fetching your pages; it governs what happens to the content afterwards.
User-agent: Google-Extended
Disallow: /


# ===========================================================================
# BLOCK C — block everything you can.
#
# Read the warning below first. This is less effective than it looks.
# ===========================================================================

# User-agent: GPTBot
# User-agent: OAI-SearchBot
# User-agent: ClaudeBot
# User-agent: Claude-SearchBot
# User-agent: Claude-User
# User-agent: PerplexityBot
# User-agent: Google-Extended
# Disallow: /


# ---------------------------------------------------------------------------
# WHAT ROBOTS.TXT CANNOT DO
#
# The user-initiated fetchers — the ones that visit a page because a person
# just asked a question about it — do not all obey robots.txt:
#
#   ChatGPT-User    OpenAI: "Because these actions are initiated by a user,
#                   robots.txt rules may not apply."
#   Perplexity-User Perplexity: "this fetcher generally ignores robots.txt
#                   rules."
#   Claude-User     Anthropic states it honours robots.txt.
#
# So a disallow stops the systematic crawlers. It does not reliably stop your
# content appearing in an answer someone asked for. If the requirement is
# genuinely "this must not be readable by an assistant", robots.txt is the
# wrong control and the content needs authentication.
# ---------------------------------------------------------------------------
