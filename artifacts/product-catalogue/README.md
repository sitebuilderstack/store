# Product catalogue artifact

Published: https://claude.ai/artifact/2JtfLp4CRneVPFaXv5pbxZ

`python3 build.py` regenerates `index.html` from the facts in `build.py` (titles, prices, SKUs, file counts as on the store on 2026-09-18) and `images.json` (the products' featured images, inlined because the artifact sandbox blocks image loads). Re-run and republish after any price or product change.
