Four tools that produce something useful before asking you for anything. No
email address, no account, no gate on the result.

They all run entirely in your browser. Nothing you type into any of them — a
project description, a site URL, a `CLAUDE.md` — is transmitted to this site, to
an analytics service, or to anyone else. The only thing recorded is which tool
was used.

## The tools

### [CLAUDE.md Starter Generator](/pages/claude-md-generator)

Answer a few questions about your project and get a starting `CLAUDE.md` — the
file Claude Code reads at the beginning of every session. Leaves out anything
you did not fill in rather than padding it with plausible defaults, because a
generated instruction you have not checked is worse than a missing one.

### [Claude Code SEO Audit Prompt Generator](/pages/seo-audit-prompt-generator)

Builds a technical SEO audit prompt scoped to your platform and situation. The
prompts demand evidence rather than summaries, forbid fixing in the same run,
and work in dependency order — and they carry the platform-specific behaviours
that cause audits to produce confident wrong answers.

### [Website Launch Readiness Score](/pages/launch-readiness-score)

Twenty-four questions, seven categories, a score out of 100 and a prioritised list.
It is a self-assessment rather than an audit: it reports what you told it. The
useful way to use it is to treat every "Yes" as a claim to verify.

### [Claude Code Website Prompt Builder](/pages/website-prompt-builder)

Turns a description of what you are building into a structured project prompt —
role, objective, a discovery phase that changes nothing, requirements,
constraints, validation and deliverables.

## Why these are free

The same reason the [guides](/blogs/guides) and the
[checklists](/pages/resources) are free. The method is not the product; the
packaged, tested version of it is. If these tools are all you need, that is a
perfectly good outcome and you owe nothing.

## What they are not

None of them audits your site. They generate prompts, files and scores from what
you tell them — they do not fetch your pages, crawl anything, or inspect
anything. Running the resulting prompt against a real repository is where the
work actually happens, and that is the part these tools set up rather than
replace.
