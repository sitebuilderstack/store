## How this list is chosen

Five tools, for five jobs the guides on this site actually describe: hosting a
site, knowing when it goes down, seeing who visits, keeping in touch with
readers, and deploying from Git. Each was picked because a guide here reaches a
point where you need something of that kind — not because of what it pays.

Every description below states what it is based on. Where this site uses the
tool, it says so and names the date. Where the description comes from the
vendor's own documentation and nothing more, it says that instead. There is no
"best", no ranking, and no score: these are five defensible choices, not the
results of a comparison nobody ran.

**Prices and free tiers were read from each vendor's official pricing page on
24 September 2026.** They change. The vendor's page is authoritative; this one
is a snapshot with a date on it.

## What is deliberately not here

**Claude Code itself.** Every guide on this site needs it, and this site is
independent of Anthropic and says so on every page. Recommending it for
commission would put a price on that independence.

**Shopify.** This store runs on it and sells a toolkit for automating it. That
is a conflict worth leaving alone.

**Anything that pays well but does not fit.** The list grows when a guide
creates a need, not when a program opens.
