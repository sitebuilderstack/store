## Do this first

Open the one closest to your project, copy it to your repository root, replace everything
in angle brackets, and then **delete about a third of it.**

That last step is not a joke. Length is the main way these files fail. Every line competes
for attention with every other line, so a 400-line `CLAUDE.md` gets followed less reliably
than a 120-line one. If you are not sure what to cut, cut the rules you have never actually
seen broken.

## The 60-second check that it is working

Start a session and ask:

> What does CLAUDE.md tell you about testing in this project?

A vague answer means a vague section. Then ask for something the file forbids — adding a
dependency, pushing straight to main. It should push back and tell you why.

If neither happens, the file is decoration.
